`hitplotr` is an R package built to take game-by-game amateur/youth baseball stats and turn them into an interactive shiny app featuring a table and cumulative season plot. 
The package includes a sample dataset, playerSample. A user should replciate this table structure with their data for best results. 
Install this package by running: 
  "remotes::install_github("elstonmiller/hitplotr")" then "library(hitplotr)".
Test it's ability with `plotHits(playerSample)`.
Review the sample data and insert your own data in identical format.
